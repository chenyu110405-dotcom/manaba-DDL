# 如何把「作业泡泡」打包分享给朋友 🎁

你可以根据朋友的电脑系统和技术情况，选择以下最适合的分享方式：

---

## 🌟 方式一：轻量压缩包（最快捷，推荐两步搞定）

本项目的源码和资源体积非常小（仅几 MB，包含了 aespa 成员精美高清头像）。

### 1. 打包步骤（你来操作）：
1. 在项目文件夹中，**排除**掉体积庞大的缓存文件夹：
   - 排除 `.venv`（虚拟环境，几百MB）
   - 排除 `.browser-runtime`（如有，浏览器缓存）
   - 排除 `.git`
2. 将其余文件压缩成一个 **`作业泡泡.zip`** 发给朋友（可以直接用微信、QQ、网盘、AirDrop 传送）。

### 2. 朋友使用步骤（发给朋友看）：

#### 如果朋友是 Windows 电脑：
1. 电脑需安装 **Python 3.10+**（从官网 python.org 或微软应用商店安装，安装时勾选 `Add python.exe to PATH`）。
2. 解压压缩包。
3. **首次使用**：双击运行 **`setup_windows.cmd`**（会自动安装运行环境和 Chromium 内核）。
4. **之后每次使用**：直接双击 **`run_windows.cmd`**，会自动启动并在浏览器打开 `http://127.0.0.1:8765/`。

#### 如果朋友是 Mac 电脑：
1. 确保电脑已安装 Python 3（终端输入 `python3 --version` 即可检查）。
2. 解压压缩包。
3. **首次使用**：双击运行 **`setup_mac.command`**。
4. **之后每次使用**：直接双击 **`run_mac.command`**，会自动启动并弹出浏览器。

## 💎 方式二：全离线免安装绿色便携版（适合完全不懂 Python 的朋友）

如果你希望朋友**完全不需要安装 Python，解压就能双击直接用**，你可以制作一个 Windows Portable 绿色免安装包：

### 制作步骤：
1. 前往 Python 官网下载 [Windows embeddable package (64-bit)](https://www.python.org/downloads/windows/)（约 10MB）。
2. 将下载的解压到项目根目录下的 `python/` 文件夹中。
3. 配置 Playwright 浏览器到项目内目录（设置环境变量 `PLAYWRIGHT_BROWSERS_PATH=./browsers` 并下载好 Chromium）。
4. 编写一个根目录下的 `启动作业泡泡.cmd`：
   ```cmd
   @echo off
   cd /d "%~dp0"
   start http://127.0.0.1:8765/
   set PLAYWRIGHT_BROWSERS_PATH=%~dp0browsers
   .\python\python.exe -m manaba_deadline serve
   ```
5. 将整个文件夹打包为 zip 发给朋友。朋友解压后双击 `启动作业泡泡.cmd` 即可秒开！

## 📦 方式三：打包成真正的独立「.exe」文件

### 为什么在 Mac 上不能直接导出 .exe？
因为 Windows `.exe` 必须在 Windows 系统（或虚拟机）环境下编译。

### 如果你或朋友有一台 Windows 电脑：
项目中已经为你写好了完整的一键打包脚本：
1. 把项目文件夹放到 Windows 电脑上。
2. 双击运行 **`build_exe.cmd`**。
3. 脚本会自动安装 PyInstaller 并编译，完成后会在 **`dist/`** 文件夹下生成 **`作业泡泡.exe`**！
4. 朋友直接双击 `作业泡泡.exe` 即可使用。

### 如果你只有 Mac 电脑（推荐：GitHub 云端免费自动编译）：
项目中已配置好 GitHub Actions 自动化工作流（`.github/workflows/build_exe.yml`）：
1. 将当前项目上传到 GitHub 仓库（公开或私有均可）。
2. 在仓库的 **Actions** 标签页，点击 **“构建 Windows EXE” -> “Run workflow”**。
3. GitHub 微软云端服务器会自动在真实的 Windows 环境下编译。
4. 几分钟后，直接在页面下方下载打包好的 **`作业泡泡-Windows-EXE.zip`**，里面就是现成的 `.exe`！

## 🔒 隐私与安全说明（放心告诉朋友）
- 密码不会保存在任何配置文件中，关闭服务后内存自动清空。
- 仅访问学校 manaba 官方页面（`https://manaba.ryukoku.ac.jp/ct/home`），不会向任何第三方服务器上传任何数据。
- 上传的自定义聊天背景只保存在朋友自己的本地浏览器 IndexedDB 中。
